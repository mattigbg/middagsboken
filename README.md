# Middagsboken

Recept, veckomeny och inköpslista för familjens middagar. Installeras på iPhone via "Lägg till på hemskärmen".

- `index.html`, `styles.css`, `app.js` – appen
- `config.js` – adress och publik nyckel till Supabase
- `supabase-setup.sql` – skapar databasen (körs en gång)
- `sw.js`, `manifest.webmanifest`, `icons/` – gör den installerbar och offline-kapabel
- `GUIDE.md` – steg-för-steg för att komma igång
